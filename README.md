# 🧠 Memory Booster

A clean, modern, and interactive memory matching game built with HTML, CSS, and Vanilla JavaScript. Designed with a premium glassmorphism UI, satisfying 3D card flip animations, and an engaging gameplay loop that challenges your working memory.

## ✨ Features

*   **Premium Aesthetic:** Beautiful glassmorphism UI with a calming pastel gradient background.
*   **3D Animations:** Smooth, hardware-accelerated 3D card flipping effects.
*   **Dynamic Difficulty:** A 5-second preview phase followed by a countdown timer that decreases as you advance levels.
*   **Performance Tracking:** Real-time tracking of Score, Level, Lives, and Moves.
*   **Star Rating System:** Awards 1 to 3 stars (⭐⭐⭐) based on your move efficiency per level.
*   **High Score Persistence:** Saves your highest score locally using the browser's `localStorage`.
*   **Satisfying Feedback:** Integrated with `canvas-confetti` for celebratory particle explosions when completing a level or breaking a high score.

## 🎮 How to Play

1.  Click **Start Game** to begin.
2.  **Memorize:** You have 5 seconds to memorize the positions of the 8 pairs on the 4x4 grid.
3.  **Match:** Once the cards flip face-down, click to reveal two cards at a time.
4.  **Survive:** Find all matching pairs before the timer runs out! 
    *   Make a wrong match? You lose 1 of your 3 lives.
    *   Lose all lives or run out of time? Game Over.
5.  **Excel:** Complete the board in as few moves as possible to earn a 3-star rating!

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3 (CSS Grid, Flexbox, 3D Transforms)
*   **Logic:** Vanilla JavaScript (ES6+)
*   **Dependencies:** [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) (via CDN)
